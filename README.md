# Accelerating Binding Affinity Predictions with Deep-Ensemble Surrogate Models and Active Learning

Surrogate models that reproduce Boltz-2 binding affinity rankings from cheap molecular fingerprints, enabling virtual screening of billion-scale libraries at a fraction of the oracle cost.

**Key results:**
- One-shot stratified training matches or beats iterative AL on global ranking at equal label budget, at roughly a tenth of the compute; AL retains an edge on sharp-end recall (R@1%) at low budgets
- Features matter more than architecture: Morgan+AtomPair concatenation is the single biggest gain (Spearman 0.759 -> 0.837 for BetterNN), while architecture changes at fixed features move it far less
- Acceleration on 1M ADRA2B is 150x / 50x / 5x depending on how many seed repeats a production protocol must pay for (divide by 1, 3, or 30). Below ~20k molecules the surrogate is not worth running
- Two-stage scheme (cheap surrogate -> oracle rescore) reaches oracle-quality top-1% for ~1-2% of full oracle cost on AmpC, SC6A4 and SGMR2; ADRA2B (30-50%) and DRD4 (50-100%) are not rescuable this way

Claims here are deliberately scoped to the targets they were measured on; each
is reproduced by the corresponding script below.

## Quick Start

The project requires Python 3.12 and is managed with [uv](https://docs.astral.sh/uv/):

```bash
uv sync
uv run python scripts/04_oneshot_vs_al.py --data-dir data/sample
```

Results are saved to `results/` as CSV tables and PNG figures. All scripts accept `--data-dir`, `--output-dir` and `--help`.

With [just](https://github.com/casey/just) installed, the same runs are available as recipes:

```bash
just              # list recipes
just exp04        # one experiment on the demo set
just fast         # everything except the two slow scripts (03, 06)
just all          # everything
just seeds        # show the seed count of each script

just data-dir=/path/to/adra2b exp04    # run against a full dataset
just exp04 --seeds 42 7 13             # override any script flag
```

All stochastic experiments default to 10 seeds (`42 7 13 100 2024 99 1 5 21 77`);
scripts `02` and `06` are deterministic and take no seeds.

A CUDA GPU is used for training when available; everything runs on CPU
otherwise, more slowly.

## Scripts

Each script corresponds to a report chapter and runs on the included ADRA2B demo dataset (10k molecules, 21 binders).

| Script | Chapter | What it does | Demo runtime |
|---|---|---|---|
| `01_molpal_baseline.py` | 2.4.1 | MolPAL active learning baseline | |
| `02_oracle_evaluation.py` | 2.4.2 | Where Boltz-2 beats docking (4 difficulty levels) | |
| `03_surrogate_models.py` | 2.4.3 | Compare DeepEns / BoltzNN / BetterNN at multiple budgets | hours - see note |
| `04_oneshot_vs_al.py` | 2.4.4 | 6-way comparison: one-shot vs iterative AL | ~20 min |
| `05_budget_and_acceleration.py` | 2.4.5 | Budget scan, acceleration factor by library size | |
| `06_difficulty_analysis.py` | 2.4.6 | Sphere exclusion, singleton / binder isolation analysis | hours - see note |
| `07_twostage_screening.py` | 2.4.7 | Enrichment factors, two-stage surrogate+oracle rescore | |
| `08_large_scale.py` | 2.4.8 | Scaling to 10M+, self-consistency difficulty probes | |

**Known performance limitation.** Two hotspots in `lib/clustering.py` are
unoptimised and dominate runtime on the demo set: `kmeans_cluster` takes about
13 minutes at 4096 dimensions, and `tanimoto_nearest_neighbor` is an O(n^2)
Python loop costing roughly 30 minutes at n=10,000. Script `06` calls the
latter once per (threshold, depth) pair even though its result does not depend
on the threshold, so scripts `03` and `06` are impractically slow on 10k
molecules. Neither hotspot uses the GPU.

## Data Format

Each dataset directory (`data/sample/`, etc.) contains:

- `library.csv` - columns: `smiles`, `zincid`, `consensus_score` (oracle), optionally `docking_score`, `boltz_prob`, `is_active`
- `binders.csv` - experimentally validated binder IDs
- `fingerprints/` - pre-computed arrays (regenerated by `lib/features.py` if missing): `morgan_2048.npz`, `atompair.npz`, plus `descriptors.npy`, `valid.npy` and `canonical_smiles.npy`

## Models

Three deep-ensemble architectures (5 members each), all trained on 4096-bit Morgan+AtomPair fingerprints:

| Model | Parameters | Loss | Notes |
|---|---:|---|---|
| DeepEns_concat | 4.9M | MSE | Simple MLP, LayerNorm+GELU. Most robust. |
| BoltzNN_v1_wide | 38.6M | MSE + ranking + BCE | Residual, dual heads. Best at extreme low budgets. |
| BetterNN | 4.8-11.1M | MSE + hinge ranking | Auto-configures by training size. 3-4x faster. |
